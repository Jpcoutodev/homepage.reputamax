# Reputamax — Landing Page

Landing page fake door para validação de demanda do Reputamax, SaaS de gestão ativa de reputação online para negócios locais brasileiros.

## Stack

- React 18 + Vite
- Tailwind CSS 3
- Lucide React (ícones)

## Setup

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

## Estrutura

Single page em [src/App.jsx](src/App.jsx) com as seções: Hero, Problema, Solução, Como funciona, Por que gestão ativa, Números, Para quem, FAQ, CTA final, Footer. Navbar fixa e botão flutuante de WhatsApp sempre visíveis.
